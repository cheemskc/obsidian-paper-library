# Paper Library 0.43.0

本版本汇总 0.42.6 之后的阅读、批注、文献管理和浏览器导入改进。浏览器扩展版本为 2.2.1。

- 原生 PDF 阅读器支持即时高亮、下划线、备注与颜色保存。新批注独立持久化，可在设置中明确选择论文后批量写入 PDF。
- 优化批注工具栏、备注编辑、图片侧栏及图片窗口拖动，减少普通批注操作的 PDF 读写。
- 改进标签筛选、标签关系图、文献详情和文献类型编辑。统一使用标准视图，旧布局设置自动归一，保留文献与分类数据。
- 改进 Paper Composer 文献对话、关联内容、翻译与资源清理。
- 浏览器识别论文后可手动选择 Collection；已有文献仍可补充 PDF 或追加分类。
- 只在检查 PDF 字节后导入。下载失败不再自动保存 HTML；遇到出版商验证时提示手动完成验证。
- 更新器从本分支实际发布仓库检查新版本。

## 安装与升级

从 Release 下载 `paper-library-0.43.0.zip`，将完整 `paper-library` 文件夹覆盖到库中的 `.obsidian/plugins/`，再重新加载插件。升级时保留原有 `data.json`、模型、缓存及论文文件。0.42.6 的更新器仍指向上游，因此需手动升级到本版一次。

浏览器扩展单独下载 `paper-library-web-importer-2.2.1.zip`，解压后在 Chrome / Edge 扩展管理页加载其 `browser-extension` 文件夹；已使用解压版扩展的用户更新目录后需重新加载扩展并刷新论文网页。
